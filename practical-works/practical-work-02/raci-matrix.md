# Матрица RACI (Самостоятельная работа №2)

**Цель:** Распределение ответственности при организации работы с репозиторием проекта и настройке Git.

## Таблица распределения ответственности

| Задача | Руководитель разработки | Архитектор ПО | Программист | Тестировщик | Специалист по данным | Исследователь |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| 1. Регистрация на GitHub | A | R | R | R | R | R |
| 2. Создание командного репозитория | A/R | C | I | I | I | I |
| 3. Создание структуры папок и файлов | A | R | R | C | C | C |
| 4. Настройка прав доступа (Collaborators) | A/R | I | I | I | I | I |
| 5. Написание документации (README, docs) | A | C | C | I | R | R |
| 6. Создание своей ветки (feature/...) | I | R | R | R | R | R |
| 7. Внесение изменений и коммит | I | R | R | R | R | R |
| 8. Создание Pull Request (PR) | C | R | R | R | R | R |
| 9. Проведение ревью (Review) | A/R | R | C | C | C | C |
| 10. Слияние веток (Merge) | A/R | C | I | I | I | I |
| 11. Подготовка итогового отчета по Git | A | C | C | I | R | R |

## Расшифровка обозначений
*   **A (Accountable)** — Ответственный за результат. Принимает финальное решение и отвечает за выполнение задачи (на каждую задачу обычно один А).
*   **R (Responsible)** — Исполнитель. Тот, кто непосредственно выполняет работу.
*   **C (Consulted)** — Консультант. С ним советуются перед принятием решений, но он не выполняет задачу.
*   **I (Informed)** — Информируемый. Тот, кого ставят в известность о результате или ходе выполнения задачи.
